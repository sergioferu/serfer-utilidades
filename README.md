
# Serfer Utilidades - CARASIR

## Descripción
Plugin personalizado para ampliar las funcionalidades
del blog CARASIR sin modificar el núcleo de WordPress.

Autor: Sergio Ferreira Ruiz
Módulo: IAW - 2º ASIR
Curso: 2026/2027

## Funcionalidades
1. Caja de contacto al final de las entradas.
2. Shortcode [anio] para mostrar el año actual.
3. Eliminación de la etiqueta generator de WordPress.
4. Personalización de la pantalla de acceso:
   - Logotipo enlazado a la portada.
   - Texto accesible del logotipo.
   - Aviso de acceso restringido.

## Requisitos
- WordPress con soporte para filtros y acciones.
- Página Contacto publicada.
- Tema hijo serfer-hijo para los estilos CSS
  de la caja de contacto.

## Instalación
1. Copiar serfer-utilidades a wp-content/plugins/.
2. Entrar en Plugins > Plugins instalados.
3. Activar Serfer Utilidades - CARASIR.
4. Comprobar las funcionalidades del plugin.

## Uso del shortcode
Insertar [anio] en un bloque Código corto.
